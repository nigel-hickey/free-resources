# Nigel's Free Resources

Welcome!

This repository contains the free templates, worksheets, and practical AI resources that accompany articles on NigelHickey.com.

Everything here is designed to help you organize information, preserve context, reduce cognitive load, and build practical systems that last.

I hope these resources save you time and help you build better systems.

## Available Resources

- [AI Project Kickoff Template](templates/AI-Project-Kickoff-Template-v1.0.md): set up any AI project with enough context to stop repeating yourself. Companion article: [Stop Starting Over With AI](https://nigelhickey.com/stop-starting-over-with-ai/)

- [Worked Example: Family Travel Project](templates/AI-Project-Kickoff-Example-Travel.md): the kickoff template filled in for a real trip, so you can see what a finished one looks like.

- [Kitchen Inventory Starter](templates/kitchen-inventory-starter/): track what's in your fridge, freezer, and pantry with whatever AI you already use, and keep a shopping list that actually makes sense a week later. Companion article: coming soon.
